Compare subtitle timing

Check whether two SRT or WebVTT files have the same cue count and timestamps, in file order. Useful for reviewing a translation before testing it with video.

Files stay in this browser for this comparison. This tool does not translate, align cues, verify meaning or prove synchronization. It compares exact times; review subtitles with the video.

UTF-8 SRT or WebVTT, up to 5 MiB and 5,000 cues per file. WebVTT cue settings, styling and cue text are not compared. A different cue count prevents a position-by-position comparison.
